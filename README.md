Train Y1 single-output ANN

Files:
- `scripts/train_y1.py`: train script that reads `Sample_Data_Sheet.csv` and saves pipeline to `models/ann_y1/`.
- `requirements.txt`: Python dependencies.

Quick run (PowerShell):

```powershell
python -m pip install -r requirements.txt
python scripts/train_y1.py --csv Sample_Data_Sheet.csv
```
